Editor Konten Website

📌 Cara pakai:
  1. Ubah konten lewat formulir di bawah (teks, jadwal, angka, gambar).
  2. Klik "Simpan & Unduh konten.json" di bagian bawah.
  3. Upload file konten.json hasil unduhan ke hosting, gantikan file lama di folder data/.
  4. Selesai — website langsung menampilkan konten terbaru.

Gambar: upload dulu gambar/flyer ke folder assets/img/ di hosting (via cPanel / FTP), lalu tulis nama filenya di kolom gambar, contoh: assets/img/flyer-kajian.jpg.

💾 Simpan Perubahan

Perubahan tersimpan ke file data/konten.json yang Anda unduh, lalu upload ke hosting.
